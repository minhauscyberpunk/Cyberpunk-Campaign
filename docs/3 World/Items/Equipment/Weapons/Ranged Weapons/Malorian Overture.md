# Description
The Overture is a [Heavy Pistol](../../../../../4%20Rules%20and%20Mechanics/Items/Equipment/Weapons/Ranged%20Weapons/Ranged%20Weapon%20Types/Heavy%20Pistol.md) manufactured by [[Malorian Arms]]. The Malorian Overture is an [Excellent Quality](../../../../../4%20Rules%20and%20Mechanics/Items/Equipment/Weapons/Ranged%20Weapons/Ranged%20Weapon%20Qualities/Excellent%20Quality.md) [Heavy Pistol](../../../../../4%20Rules%20and%20Mechanics/Items/Equipment/Weapons/Ranged%20Weapons/Ranged%20Weapon%20Types/Heavy%20Pistol.md) designed like a revolver. It is incompatible with magazine attachments.
